## この講義の問い

自分が抱えている問題が、第2講のコストを払うだけの問題なのかを、どう見分けるのか。

## 実習資料

### 準備

判定ワークシートに自分のプロジェクトを当てはめてみる。1番から順に答え、ノーが出たらその行で止める。反証の項目は1〜5番をすべて通過したときだけ答え、イエスなら脱落である。根拠の欄は一行で書き、状況が変わったら根拠から確かめ直す。

### 空の様式

| # | 問い | イエス / ノー | 根拠一行 |
|---|---|---|---|
| 1 | 一つの状態を共有すべき主体が二つ以上あるか？ | | |
| 2 | その主体同士が互いに敵対しうるか？ | | |
| 3 | 全員が受け入れる第三者がいないか、その第三者自体がリスクか？ | | |
| 4 | 記録の順序と事後の不変性が、紛争で証拠として必要か？ | | |
| 5 | 分散のコスト（第2講）を払っても余るほど、その価値が大きいか？ | | |
| 反証 | 最終決定権の行き着く先が、結局一つの主体の鍵なのか？ | | |
| 判定 | | 通過 / 脱落（止まった項目） | |

### 記入例：数千人の同窓会の会費帳簿（会計係が管理者鍵を一人で持っている場合）

| # | 問い | イエス / ノー | 根拠一行 |
|---|---|---|---|
| 1 | 一つの状態を共有すべき主体が二つ以上あるか？ | イエス | 全国の支部すべてが同じ帳簿を見る必要がある |
| 2 | その主体同士が互いに敵対しうるか？ | イエス | 支部ごとの会費配分をめぐって利害が分かれる |
| 3 | 全員が受け入れる第三者がいないか、その第三者自体がリスクか？ | イエス | 会計係選びから揉める、みんなが信用する監査法人がない |
| 4 | 記録の順序と事後の不変性が、紛争で証拠として必要か？ | イエス | 未納の紛争で帳簿の順序がそのまま証拠になる |
| 5 | 分散のコスト（第2講）を払っても余るほど、その価値が大きいか？ | イエス | 奨学基金の規模、支部間の訴訟の可能性 |
| 反証 | 最終決定権の行き着く先が、結局一つの主体の鍵なのか？ | イエス | 管理者鍵を会計係が一人で保有 |
| 判定 | | 脱落（反証） | 管理者鍵を支部の代表数人で分けて持つ構造に変えたら、判定し直す |

会費、箱の数、銀行の数のような数字は、仮定した例の値である。
