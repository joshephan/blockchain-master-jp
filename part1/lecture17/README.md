# 第17講 EIP-1559とブロックガスリミット

第1部 基盤：ブロックチェーンとEVM・第4章 イーサリアムと状態マシン

[← 第16講](../../part1/lecture16/) | [第1部 目次](../) | [第18講 →](../../part1/lecture18/)

## この講義の問い

第16講のガスは、トランザクション一つのリミットだった。ブロック一つ、つまり世界中が12秒でできる計算にもリミットがある。その枠をめぐって、値段はどう決まるのか。

## 実習資料

### 準備

Foundryの`anvil`（ローカルのテストチェーン）と`cast`だけあればよい。送金にはanvilの既定テストアカウントの公開された鍵を使う。下の値はすべてローカルのテストチェーンの値である。1、2は既定設定のanvil、3はブロックガスリミットを送金二件分に減らし自動マイニングを切ったanvil（`--gas-limit 42000 --no-mining`）で、`cast rpc anvil_mine`でブロックを直接作る。

### 実行結果

**1. ベースフィーと空のブロック。** 既定のanvilの最初の値は、ブロック番号0、`cast base-fee` 1000000000（1 gwei）、`cast gas-price` 2000000000、ブロックガスリミット30000000である。空のブロックを4個作ると（`anvil_mine 1`、`anvil_mine 3`）、ベースフィーがブロックごとに8分の1ずつ下がる：

```
block 0 baseFee=1000000000
block 1 baseFee=1000000000
block 2 baseFee=875000000
block 3 baseFee=765625000
block 4 baseFee=669921875
```

**2. 送金一件の実際の単価。** チップ2 gwei、最大10 gwei（`--priority-gas-price 2gwei --gas-price 10gwei`）で1 ETHを送った結果。トランザクションに書かれた値と、レシートの実際の値である：

```
maxFeePerGas          10000000000
maxPriorityFeePerGas  2000000000
gasUsed               21000
effectiveGasPrice     2586181641
ブロック5 baseFeePerGas  586181641
```

実際の単価は、ベースフィー0.586181641 gweiにチップ2 gweiを足した2.586181641 gweiである。最大10 gweiのうち使わなかった分は払わない。最大手数料をベースフィーより低く（チップ0、最大0.1 gwei）すると拒否される：

```
Error: server returned an error response: error code -32003: max fee per gas less than block base fee
```

**3. いっぱいのブロック、チップの順番、ナンスの空き。** ブロックガスリミット42,000でブロックごとに送金2件を入れるとブロックがいっぱいになり、ベースフィーがブロックごとに8分の1ずつ上がる：

```
block 1 gasUsed=42000 baseFee=1000000000
block 2 gasUsed=42000 baseFee=1125000000
block 3 gasUsed=42000 baseFee=1265625000
```

6番ブロックの直前にA（チップ1 gwei / 最大3 gwei）、B（チップ3 gwei / 最大5 gwei）、C（チップ2 gwei / 最大4 gwei）をこの順で送ると、二つの枠はチップの高いB、Cが取り、Aは次のブロックに押し出される：

```
block 6 gasUsed=42000 baseFee=1601806640   含まれた順: B(0x71018d...), C(0x3794f9...)
block 7 gasUsed=21000 baseFee=1802032470   含まれた: A(0xae5503...)
```

ナンスが2のアカウント（`0x3C44CdDdB6a900fa2b585dd299e03d12FA4293BC`）がナンス3をチップ5 gweiで先に送ると、8番ブロックは空になり、ナンスは2のままである。抜けたナンス2をチップ1 gweiで送ると、9番ブロックにナンス2、3が一緒に入り、ナンスは4になる：

```
block 8 gasUsed=0     baseFee=1802032470
block 9 gasUsed=42000 baseFee=1576778412   ナンス2、3が一緒に含まれた
```

### 試すときの注意

- anvilの既定の並べ方（`--order fees`）は、最大手数料とチップがともに高いほうを前に置く。上のA、B、Cは、最大手数料とチップを同じ順番にそろえて送った。
- anvilの既定のブロックガスリミット（30000000）はメインネットの値と違う。メインネットの値は下の時効性のあるデータを見る。

## 時効性のあるデータ

基準日時点の値。時間がたつと変わることがある。

| 項目 | 値 | 基準日 |
|---|---|---|
| イーサリアムメインネットのブロックガスリミット | 約6,000万ガス（直近24時間のブロック300個の標本で59,941,351〜60,058,592）。既定値60MはEIP-7935 | 2026-10-20 |
| ブロックのガスの目標値 | 約3,000万ガス（リミットの半分） | 2026-10-20 |
| ブロックあたりの単純な送金の数 | 約2,857件（60,000,000 ÷ 21,000） | 2026-10-20 |
| 最近のベースフィーの範囲 | 直近約9,200ブロック（約1.3日）のベースフィー0.032〜0.556 gwei、中央値0.064。30日分は日平均のガス価格で代用：2026-09-20〜10-19で0.57〜2.35 gwei | 2026-10-20 |
| ツールのバージョン | Foundry（anvil、cast）1.8.3 | 2026-10-17 |
