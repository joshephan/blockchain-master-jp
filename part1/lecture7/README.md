## この講義の問い

第2講で述べたコスト（すべてを計算し直すこと）を全部払わなくても、自分のトランザクションがブロックに入ったことを確かめられるのか。

## 実習資料

### 準備

Foundryの`cast keccak`だけで、葉8個のマークルツリーを自分で計算する。葉は文字列"T1"〜"T8"のkeccak256、上の段は二つのハッシュをつなげた64バイト（`0x` + 左のハッシュ + 右のハッシュ）のkeccak256である。説明用の単純なツリーであり、ビットコインやイーサリアムが実際に使うツリーの規格（ハッシュ関数、エンコーディング、ペアが奇数のときの処理）とは異なる。

- 上の段のハッシュは、二つのハッシュを文字列としてつなげるのではなく、バイトとしてつなげてハッシュする。`cast keccak`に`0x`で始まる値を渡すと、バイトとしてハッシュする。
