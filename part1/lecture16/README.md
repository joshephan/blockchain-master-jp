## この講義の問い

第14講で残した問い：ループを許した機械で、無限ループを何で防ぐのか。そして、命令ごとに値段を変えた理由は何か。

## 実習資料

### 準備

Node.jsだけあればよい。外部パッケージは使わない。

### コード

| ファイル | 内容 |
|---|---|
| [code/steps.js](code/steps.js) | コラッツの反復（偶数なら2で割り、奇数なら3n + 1）が1に届くまで何回回るかを数える。入力ごとの反復回数を前もって知るのは難しいという例 |

### 実行結果

`node steps.js`の出力（node v24.11.0）。7は16回、27は111回回る。

```
16
111
```

## 時効性のあるデータ

基準日時点の値。ガスの料金表はアップグレードのたびに変わることがある。

| 項目 | 値 | 基準日 |
|---|---|---|
| 単純な送金一件の基本ガス | 21,000ガス | 2026-10-20 |
| ADD / MUL | 3 / 5ガス（大阪（Osaka）基準） | 2026-10-20 |
| MLOAD / MSTORE | 3ガス + メモリ拡張コスト | 2026-10-20 |
| SLOAD | コールドアクセス 2,100 / ウォームアクセス 100ガス | ベルリン（2021.04）以降 |
| SSTORE、0から0でない値 | 20,000ガス（コールドな欄なら + 2,100） | ベルリン（2021.04）以降 |
| SSTORE、0でない値を別の値に | 2,900ガス（コールドな欄なら + 2,100） | ベルリン（2021.04）以降 |
| アカウントへのアクセス（BALANCE、EXTCODESIZE、CALLの対象など） | コールドアクセス 2,600 / ウォームアクセス 100ガス | ベルリン（2021.04）以降 |
| アクセスリストの項目の前払い | アドレス1個 2,400 / ストレージの欄1個 1,900ガス | ベルリン（2021.04）以降 |
| EIP-150の前後：EXTCODESIZE | 20 → 700ガス | タンジェリン・ホイッスル（2016.10.18） |

| EIP-150の前後：CALL、CALLCODE、DELEGATECALL | 40 → 700ガス | タンジェリン・ホイッスル（2016.10.18） |
| ブロック一つのガス総量とトランザクション一つのガスの上限 | ブロック約6,000万ガス（直近24時間のブロック300個の標本で59,941,351〜60,058,592、既定値60MはEIP-7935）。トランザクション一つの上限は16,777,216（2の24乗、EIP-7825、Fusaka（2025-12-03）で適用） | 2026-10-20 |
