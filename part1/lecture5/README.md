## この講義の問い

第4講で、いちばん下の層にいくつかの関数があると述べた。その関数は何を保証し、何を保証しないのか。

## 実習資料

### 準備

Foundryの`cast`とNode.jsが必要である。別のプロジェクトやチェーンは必要ない。

### 実行結果

`cast keccak "hello"`と`cast keccak "hellp"`の出力。一文字の違いで値がまったく変わる。

```
0x1c8aff950685c2ed4bc3174f3472287b56d9517b9c948127319a09a7a36deac8
0x7bc9c272894216442e0ad9df694c50b6a0e12f6f4b3d9267904239c63a7a0807
```

Node.js `crypto`の`sha3-256`で同じ"hello"をハッシュした出力（`node -e "console.log(require('crypto').createHash('sha3-256').update('hello').digest('hex'))"`）：

```
3338be694f50c5f338814986cdf0686453a888b84f424d792af4b9202398f392
```

### 試すときの注意

- イーサリアムのkeccak256とNISTのSHA3-256（FIPS 202）は、同じ入力に対して違う値を出す。違いは入力の末尾を埋めるパディングのルールにある。
- Node.js `crypto`の`sha3-256`はFIPS 202の標準なので、イーサリアムの値と照合するのには使えない。
- ハッシュ値はツールのバージョンに関係なく固定である。
