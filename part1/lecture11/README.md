## この講義の問い

ウォレットで「送信」を押した瞬間から「終わった」と言えるまで、トランザクションはどんな段階を通り、各段階で何がまだ決まっていないのか。

## 時効性のあるデータ

基準日時点の値。時間がたつと変わることがある。

| 項目 | 値 | 基準日 |
|---|---|---|
| ビットコインの手数料水準（sat/vB） | 速い 2 / 30分以内 1 / 1時間以内 1 / 最小 1 sat/vB | 2026-10-20 |
| 取引所ごとのビットコイン入金確定ブロック数 | Bithumb 1 / Binance 1（出金解除 2） / Coinbase 2 / Upbitは公開ページにコンファメーション数なし | 2026-10-20 |
| 取引所ごとの他のコインの入金確定ブロック数（ハッシュパワーの小さいチェーンとの比較用） | ETC Bithumb 1,000 / Binance 70 / Coinbase 3,000・BCH Bithumb 60 / Binance 2 / Coinbase 12・LTC Binance 3 / Coinbase 6（Upbit・Bithumbは未上場）・ETH Bithumb 33 / Binance 6（出金解除 64） / Coinbase 14 / Upbitは公開ページになし | 2026-10-20 |
| 主要ノードソフトウェアの置き換え（RBF）の既定動作 | 表示がなくても置き換えを受け入れる。Bitcoin Core 28.0からmempoolfullrbfの既定が1、29.0でオプション削除（full RBFが標準）、30.0の文書でもBIP-125の表示は不要。最新はv31.1 | 2026-10-20 |
