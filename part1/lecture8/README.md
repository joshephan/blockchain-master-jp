## この講義の問い

ビットコインは残高をどこに、どんな形で書いているのか。

## 実習資料

### 準備

Node.jsだけあればよい。外部パッケージは使わない。金額はサトシ（1 BTC = 100,000,000）単位のBigIntで計算する。UTXO A、B、Cの金額と手数料0.0001 BTCは、説明用の仮定の値である。

### コード

| ファイル | 内容 |
|---|---|
| [code/utxo.js](code/utxo.js) | ウォレットの中のUTXO三つでボブに0.6 BTCを送りながら、入力、出力、おつり、手数料を計算する例 |

### 実行結果

`node utxo.js`の出力。残高は保存された値ではなくUTXOの合計で計算した値であり、手数料は入力の合計から出力の合計を引いた値である。

```
残高（計算値）: 0.75000000 BTC
入力: A 0.50000000 BTC, B 0.20000000 BTC 合計 0.70000000 BTC
出力: ボブ 0.60000000 BTC
出力: 自分のおつりのアドレス 0.09990000 BTC
手数料 = 入力の合計 - 出力の合計 = 0.00010000 BTC
おつりの出力を忘れると手数料 = 0.10000000 BTC
送金後の自分のUTXO: C 0.05000000 BTC, D 0.09990000 BTC
残高（計算値）: 0.14990000 BTC
0.5で0.3を送るときのおつり: 0.19990000 BTC / 手数料: 0.00010000 BTC / おつりを忘れると手数料: 0.20000000 BTC
```

### 試すときの注意

- トランザクションには手数料を書く欄がない。おつりの出力を忘れると、差額がすべて手数料としてマイナーに渡る。

## 時効性のあるデータ

基準日時点の値。時間がたつと変わることがある。

| 項目 | 値 | 基準日 |
|---|---|---|
| ビットコインの手数料の水準 | 高速 2 / 30分以内 1 / 1時間以内 1 / 最低 1 sat/vB | 2026-10-20 |
| ブロックあたりのトランザクションの規模 | ビットコインはブロックあたり平均約4,457件（24時間で695,298件 ÷ 156ブロック） | 2026-10-20 |
