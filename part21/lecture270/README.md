## この講義の問い

「どれだけ分散しているか」に数字で答えられるのか。その数字は何を数え、何を数えられないのか。同じ体系が数字一つに要約されるのか。

## 実習資料

### 準備

Pythonの標準ライブラリ（`fractions`、`urllib`）だけを使うスクリプト一つでナカモト係数を数える。持ち分はすべておもちゃのデータである（バリデーターの運営主体十二か所、クライアント四つ、代理人五人、Marketの層ごとの係数）。引数なしで実行するとおもちゃの節だけが動き、RPCのアドレスを渡すと、そのanvilで`anvil_setCoinbase`と`anvil_mine`でブロック1〜20を作ったあと（a1 8個、b2 5個、c3 4個、d4 3個）、ブロックヘッダーのminerの欄を数える。anvilはFoundry 1.8.3をデフォルトの設定で立ち上げる。

### 試すときの注意

- 同じ分布でも、しきい値によって係数が違う（1/3超で2、1/2超で3、2/3以上で5）。1/3は「超」、2/3は「以上」で数える。係数を言うときは、しきい値を一緒に書く。
- 持ち分は小数ではなく分数（`Fraction`）で足さないと、境目で間違える。たとえば十二か所が同じだけ分け合うと、四つでちょうど1/3なので、1/3を超えるには五つが必要である。
- アドレスで数えると、係数が実際より大きく見えることがある（Aをアドレス六つに分けると3、まとめると2）。まとめる根拠（オペレーターが明かした一覧、お金が出ていく流れなど）はチェーンの外で探し、係数の横に書く。
- anvilのブロックヘッダーのminerの欄は、`anvil_setCoinbase`で決めたアドレスである。チェーンに書かれたアドレスは主体ではない。
- 同じ層の中でも、何を止めるかによって数が分かれる（管理者キーの設定2、停止1）。層ごとの係数を平均せず、いちばん小さい値を体系の係数として書く。
