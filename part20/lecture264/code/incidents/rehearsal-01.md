## 6. 外に知らせた文
- 最初のお知らせ(ブロック51のあと): 分かっていること = COLの価格の出どころがブロック49で0を書き、COLの30分平均が下がっている途中 / したこと = COLの預け入れ・借り入れを停止(ブロック51)、出どころのオペレーターに連絡 / ユーザーが今できること = 引き出し・返済はできる。COLを担保に借りたアカウントは借金を減らせば清算ラインから遠ざかる / 分かっていないこと = 出どころがいつ直るか / 次の通知 = 出どころが直るか30分後
- 二つ目の練習(出どころの停止)のお知らせ: ユーザーが今できること = 返済、担保でない資産の引き出し。COLを担保としてオンにしたアカウントは、借金がなければCOLを全部引き出すか担保をオフにできる。一部だけの引き出しはできない。借金があれば先に全部返す
