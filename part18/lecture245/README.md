## この講義の問い

「いまこの市場は帳簿どおりに動いているか」に画面1枚で答えるには、何を表示すべきか。判定の基準はどこから持ってくるのか。その画面の数字はいつの値で、何によって信じられるのか。

### 試すときの注意

- パネルごとに、上に「何番ブロックまでの答えか」をまず置く。予約実行が失敗すると、画面は古い数字をそのまま見せる。
- パネル1の判定式は「金庫のトークン + 貸し出した借金 < 預けた人が引き出す量なら警報」である。この7日間は借りた人がいなくて借金が0なので、帳簿と金庫だけを比べる。
- StatusChangedのログには数字しかない。名前はソースのenumの順番から付ける。
- 帳簿の欄（totalDeposits）には、利子の指数で割った持ち分が入る。この7日間は指数が1である。
