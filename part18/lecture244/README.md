## この講義の問い

プロトコルが帳簿どおりに動いているかを見るには、何を数えるべきか。指標一つはコードのどの行にぶら下がっていて、その値は何と突き合わせれば信じられるのか。数えられない指標はどう書くのか。

### 試すときの注意

- 帳簿で数えた残高と金庫のトークン残高は違うことがある。直接送ったトークンは金庫側だけを増やし、移すときに手数料を引くトークンは金庫側の増え方が少なくなる。
- 帳簿の欄（totalDeposits）には、利子の指数で割った持ち分が入る。この7日間は借りた人がいないので指数が1で、持ち分とトークンの量が同じである。
- 健全性の比率のように、ログで数える行がない指標は、状態を直接読まなければならない。
- 失敗した取引はログがないので、失敗率と失敗の手数料はtransactionsの表で数える。
