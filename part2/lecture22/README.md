# 第22講 Remixとブラウザでの実行

第2部 開発とテスト環境・第5章 ツールチェーンとコンパイラ

## この講義の問い

インストールなしにブラウザでコントラクトを書き、デプロイし、呼び出しまでしてくれるツールは何を代わりにやってくれて、そのせいで何を見えなくするのか。

## 実習資料

### 準備

ブラウザでRemix（remix.ethereum.org、アクセスするとapp.remix.liveに移動）を開く。インストールするものはない。ファイルエクスプローラーで`Counter.sol`を作り、下のソースを貼りつけたあと、次の順番でたどる。

1. Solidityコンパイラのパネルで0.8.20以上のバージョンを選んでコンパイルし、緑のチェックとABI・バイトコードのコピーボタンを確認する。
2. 同じパネルで0.8.20未満のバージョンに変えてコンパイルが拒否されるメッセージを見たあと、範囲内のバージョンに戻す。
3. デプロイと実行のパネルで、環境欄がRemix VMであることと、アカウント欄の残高を確認してDeployを押す。
4. デプロイされたコントラクトを開いてincrement、countを順に押し、ターミナルの行を開いてステータス・ハッシュ・from・to・ガス・解釈された入力と出力を見る。
5. countが0のコントラクト（新しくデプロイ）でdecrementを押し、ターミナルの失敗表示とcountの値0を確認する。

### コード

| ファイル | 内容 |
|---|---|
| [code/src/Counter.sol](code/src/Counter.sol) | `pragma solidity ^0.8.20`、incrementとdecrementを持つCounter |

### 実行結果

同じソースをローカルのforgeでコンパイルだけ確認した結果（`forge build --use 0.8.30 --offline`）：

```
Compiling 1 files with Solc 0.8.30
Compiler run successful!
```

Remixで出るアドレス、ハッシュ、ガスの数字は実行のたびに違うため書かない。

### 試すときの注意

- Remix VMはブラウザの中の仮想チェーンである。再読み込みすると、デプロイしたコントラクトとアカウントの残高が最初に戻る。
- countが0のときのdecrementは0.8系の算術検査にかかって失敗し、countは0のままである。
