## この講義の問い

裁定取引の機会はなぜ生まれ、なぜすぐに消えるのか。そして、その機会を作るのは誰の取引なのか。

## 実習資料

### 準備

この講義は新しいコードを実行せず、講義用のプールToyAmm（コードは[第225講 code/src/ToyAmm.sol](../lecture225/code/src/ToyAmm.sol)）の`getAmountOut`の式で手計算する。プールの手数料は30（0.3%）である。

```solidity
function getAmountOut(uint256 amountIn, uint256 reserveIn, uint256 reserveOut) public view returns (uint256) {
    uint256 inWithFee = amountIn * (10_000 - feeBps);
    return inWithFee * reserveOut / (reserveIn * 10_000 + inWithFee);
}
```

受け取る量 = 入れる量 × 9970 × 出す側の残高 ÷ (入れる側の残高 × 10000 + 入れる量 × 9970)

### 手計算の結果

| 計算 | 結果 |
|---|---|
| 1000/1000のプールにA 100 | B 90.661、残高 1100 / 909.339、価格 0.8267 |
| 10000/10000のプールにA 100 | B 98.716 |
| 1000/1000のプールにA 50、すぐ続けてもう一度A 50 | 47.483（残高 1050 / 952.517） + 43.172 = 90.655 |
| 手数料2回 | 1 − 0.997² = 0.5991% |
| 差が閉じる価格の比 | 1 ÷ 0.997² ≈ 1.0060 |
| 0.5%の差の最初の1単位 | 1.005 × 0.997² ≈ 0.99898（残らない） |
| 2%の差の最初の1単位 | 1.02 × 0.997² ≈ 1.01389（約1.4%） |
| 価格への影響なしに手数料だけ引いた値と受け取った値の差 | 99.7 − 90.66 ≈ 9.04 |

1000/1000のプールで、入れる量ごとの1個あたりの受け取る値（第194講の価格への影響の表）：1 → 0.996、10 → 0.987、100 → 0.907、500 → 0.665、1000 → 0.499。

### 試すときの注意

- 画面の計算は小数第2位（価格は第3位）で四捨五入した値である。テスト出力の値は第194講・第225講の出力そのままである。
- 二つのプールの価格が開いても、その差が2回の交換の手数料（約0.6%）とガスを超えないと残らない。交換するほど、安いプールの価格は上がり、高いプールの価格は下がる。
- 大きな交換を2回に分けてすぐ続けて入れても、受け取る量はほとんど同じである（90.655対90.661）。分けて減らすには、2回のあいだにプールの価格が戻る時間がなければならない。
- 価格への影響の分は、送る前に`quote`で前もって見える。
